# Kira Real Estate Design System

## Design read

Kira Real Estate is now a faithful, rebranded reconstruction of the supplied EstateX reference. The source composition is preserved: compact cream navigation, graphic split hero, circular property-category story, service carousel, two-column about panel, dense listing grid, dark testimonial feature, four-step process, advisor grid, property highlights, editorial news and a dark footer with an orange CTA.

Reading this as: a reference-matched real estate marketing site for Ethiopian property buyers, with EstateX's clean orange-and-white visual language and responsive card choreography.

- `DESIGN_VARIANCE: 6` - asymmetric hero and shaped imagery, with otherwise disciplined grids
- `MOTION_INTENSITY: 5` - reveal, carousel and tactile hover motion only
- `VISUAL_DENSITY: 5` - compact service, listing, advisor and article modules like the source

## Reference fidelity

- Desktop source: `.codex-captures/provided-reference/estatex-desktop-full.png`
- Mobile source: `.codex-captures/provided-reference/estatex-mobile-full.png`
- Match the source hierarchy, proportions, section order, responsive stacking and motion behaviors.
- Replace source brand, logo, copy, portraits and property imagery with Kira-owned or open-source equivalents.

## Visual language

- Warm ivory and white alternating sections
- Near-black typography and footer
- Bright restrained orange for primary actions, active details and pricing
- Condensed display typography paired with a neutral interface sans
- Rounded image frames, cards and buttons matching the reference radius system
- Circular image masks, clipped hero photography and small orbit-like decorative details

## Typography

- Display: Barlow Condensed
- Interface and body: Manrope
- Fluid hero scale with two-line desktop and compact mobile composition
- Body minimum 16px with 45-70 character reading measures

## Layout

- Maximum content width: 1400px
- 8px spacing basis with 16, 24, 32, 48, 64, 96, and 128px rhythm
- Desktop grids collapse to intentionally composed single-column mobile layouts below 768px
- Search and filter touch targets are at least 44px

## Motion

- Animate transform and opacity only
- Image zoom signals clickable property media
- Drawer and lightbox transitions communicate state changes
- Favorite and submit feedback acknowledge actions
- All automatic motion respects `prefers-reduced-motion`

## Property finder

- Deep navy architectural shell with white controls and the Kira cobalt search action
- Five-column desktop layout, two-column tablet layout, and a readable stacked mobile card
- Slight hero overlap creates hierarchy without covering the headline or primary actions
- Native select controls retain predictable keyboard and touch behavior

## Reference interpretation

- Keep the usable hero-search relationship and scannable listings
- Keep editorial scale and cinematic architectural photography
- Keep asymmetrical corporate grids and honest sample statistics
- Reject copied logos, exact compositions, inflated claims, and template-like repeated cards
